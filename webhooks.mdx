## Webhook Overview

Webhooks allow HRMex to send real-time notifications to your application when events occur. Set up endpoints to receive and process these events.

<ParamField header="X-HRMex-Signature" param-type="string" required="true">
  HMAC signature for verifying webhook authenticity.
</ParamField>

## Setting Up Webhooks

<Steps>
  <Step title="Create Endpoint" icon="server">
    Develop a secure HTTPS endpoint to receive webhook payloads.
  </Step>
  <Step title="Register URL" icon="link">
    Add your endpoint URL in the HRMex webhook settings.
  </Step>
  <Step title="Test Connection" icon="check-circle">
    Send test events to verify your endpoint is working.
  </Step>
  <Step title="Go Live" icon="play">
    Enable webhooks for production events.
  </Step>
</Steps>

## Event Types

HRMex sends webhooks for various HR-related events.

<Tabs>
  <Tab title="Employee Events" icon="user">
    Notifications for hires, terminations, and status changes.
    
    <CodeGroup tabs="JSON">
      ```json
{
  "event": "employee.hired",
  "data": {
    "employee_id": 123,
    "name": "John Doe",
    "hire_date": "2024-01-15"
  }
}
      ```
    </CodeGroup>
  </Tab>
  <Tab title="Performance Events" icon="bar-chart">
    Updates on reviews, goals, and performance metrics.
    
    <Callout kind="info">
      Performance webhooks include detailed review data.
    </Callout>
  </Tab>
</Tabs>
